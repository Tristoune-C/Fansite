Le Death Note

Qu'est ce que le Death Note ?

Le Death Note est un mysterieux cahier appartenant aux Shinigamis, les dieux de la mort. Tout humain dont le nom est inscrit dans ce cahier meurt, a condition que son visage soit connu de celui qui ecrit le nom.

Comment fonctionne-t-il ?

Le fonctionnement du Death Note repose sur quelques principes simples : il suffit d'ecrire le nom d'une personne en visualisant son viage pour provoquer sa mort. Par defaut, la victime meurt d;une crise cardiaque apres 40 secondes, mais il est possible de preciser les circonstances et les details de sa mort, dans certaines limites.

Le role de Ryuk

Ryuk est le Shinigami qui abandonne volontairement son Death Note dans le monde des humains, et Light Yagami finit par le trouver. Fascine par le monde humain et simplement motive par son ennui, il observe les actions de Light sans reellement prendre parti, devenant ainsin un temoin essentiel de l'histoire.

Quelles sont ses regles

- Le nom : le nom de la victime doit etre ecrit correctement.

- Le visage : il faut visualiser le visage de la personne pour eviter de toucher quelqu'un portant le meme nom.

- Le delai : si aucune cause de deces n'est precisee dans les 40 secondes, la victime meurt d'une crise cardiaque.

- Les circonstances : les details de la mort peuvent etre ajoutees dans les 6 minutes et 40 secondes suivantes sous certaines conditions.
